\section{Scope}\label{sec:scope}
We test the data acquisition modules (collector, mock API, producers) and the pre-processing modules (Kafka contract check, speed layer, Parquet sink and hourly aggregates of the batch layer). All tests are automated \ep{pytest} unit tests. They use no network and no Docker: API responses come from recorded payloads, Kafka, MongoDB and HTTP are replaced by fakes, and time comes from a fake clock. Tests that need a local Spark session run separately in the project's Spark container.

The tests ran on 21~Nov 2026 with \ep{pytest} 9.2.0 and Python 3.11.18: the unit tests on Windows 11 with \ep{uv run pytest -m "not spark and not live"}, the Spark tests in the Spark container (Linux) with \ep{docker compose --profile spark run --rm --no-deps speed pytest -m spark}. Each group in Sections~\ref{sec:functional} and~\ref{sec:quality} lists how many tests it holds and how many passed; Section~\ref{sec:results} holds the log.
